# Fantasy GM Agent

An advanced, fully autonomous Fantasy Football AI Agent that manages your ESPN Fantasy Football team. It uses Large Language Models (Gemini, Anthropic Claude, or OpenAI GPT) to analyze trades, monitor the waiver wire, and optimize your lineup based on live matchup data. 

All actions are sent to your phone via Telegram, where you can simply click `[Approve]` or `[Reject]` to execute the changes directly on ESPN.

## Setup Guides

### 1. Telegram Bot Token & Chat ID
1. Open Telegram and search for **@BotFather**.
2. Send `/newbot` and follow the prompts to create your bot.
3. BotFather will give you a **HTTP API Token** (e.g. `123456789:ABCDefghIJKLmnop...`). Save this!
4. To get your **Chat ID**, search for **@userinfobot** on Telegram and hit Start. It will output your ID (e.g. `123456789`). Save this!
5. Send a message to your newly created bot to open the chat history.

### 2. AI Model API Keys (Gemini is recommended)
The agent supports Gemini (default), Anthropic, and OpenAI. You only need to provide an API key for one of them.
- **Gemini (Recommended, Free Tier Available):** Go to [Google AI Studio](https://aistudio.google.com/app/apikey), click "Create API key", and copy the token.
- **Anthropic Claude:** Go to the [Anthropic Console](https://console.anthropic.com/settings/keys) and generate a key.
- **OpenAI:** Go to the [OpenAI Platform](https://platform.openai.com/api-keys) and generate a key.

### 3. ESPN Cookies (For Private Leagues)
If your league is private, you need your `ESPN_S2` and `SWID` cookies to access the API.
1. Log into your ESPN fantasy league on a web browser.
2. Open Developer Tools (Right Click > Inspect > Application > Cookies).
3. Find the values for `espn_s2` and `SWID` and save them.

## Installation

1. Clone this repository.
2. Run the interactive install script:
   ```bash
   ./install.sh
   ```
   *This will prompt you for your API keys and ESPN cookies, create your `.env` file, and install all python requirements.*

3. Start the agent:
   ```bash
   python src/gm_agent.py
   ```

## Features
- **Injury Cascade**: Runs 4 times a day to check for newly injured players. If an active starter gets injured, it instantly scans the waiver wire and proposes an add/drop replacement.
- **Waiver Scout**: Runs every Tuesday night to evaluate your worst bench players against the top 30 available free agents, using AI to propose the most optimal waiver claim.
- **Trade Analyzer**: Scans all opponent rosters and proposes mathematically optimal "Buy Low / Sell High" trades. 
- **Agentic Memory**: Learns from your decisions. When you reject a trade or lineup move via Telegram, it writes that decision to its long-term memory so it doesn't suggest it again.
- **The Commish Persona**: All Telegram alerts are delivered with a sassy, aggressive trash-talking persona generated by the AI.
